# this is my partial project

It is basically an image editor for the formats jpg and png, where we should be able to do three main actions to a given image

1. rotate a rectangular region by an angle
    - for 90, 180, 270 deg
2. crop image to a rectangular region 
3. invert colors 


As i am using JavaFX, i need another approach to editing the image because it is different from the buffered image we are used to
